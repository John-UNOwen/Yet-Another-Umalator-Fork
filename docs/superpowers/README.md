# superpowers: archived plans and specs

Inherited from upstream (TheCing/uma-tools): dated implementation plans (`plans/`) and their
matching design specs (`specs/`), written by upstream's agent workflow. Kept as a record of
how features like the mechanics explorer, the Canva slug routing, the `@google/genai` OCR
migration and the OCR proxy abuse protection were built.

They are **not** current on this fork:

- Several describe the v1 esbuild app, the JP app and the HP calculator, all removed here.
- Anything about Cloudflare Pages, Pages Functions, `_redirects` or the `umalator.app`
  worker stack is upstream's deployment; this repo deploys one static app to GitHub Pages.
- Checkbox state reflects upstream's run at the time, not this repo.

Read them for the reasoning. Check the code and [CLAUDE.md](../../CLAUDE.md) for what is
actually true.
